# 什麼是好的簡報：研究整理

整理自學術期刊、簡報設計公司與教學設計原則。把「看得懂」和「看起來漂亮」分開說明。

## 一、好的簡報：讓人看得懂

| 原則 | 說明 | 來源 |
|---|---|---|
| 每頁只講一個重點 | 複雜的內容拆成好幾頁逐步呈現；如果觀眾無法用一句話說出這頁的重點，就該拆頁。 | PLOS、Decktopus |
| 3 秒內看懂 | 觀眾看一眼就能理解這頁在講什麼（Duarte 的 Glance Test）。 | Duarte |
| 標題直接寫結論 | 寫「循環杯減量效果最好」，而不是「方案比較」。 | PLOS |
| 只放會講到的內容 | 沒有要講的細節不要放；刪掉裝飾性或離題的內容。 | PLOS、Mayer |
| 不講也看得懂 | 就算觀眾沒聽到講解，也能看懂這頁的重點。 | PLOS |
| 頁數配合時間 | 每頁大約 1 分鐘，20 分鐘的報告約 20 頁。 | PLOS |

## 二、漂亮的簡報：視覺規則

| 項目 | 建議 | 來源 |
|---|---|---|
| 顏色 | 2～3 種：中性背景、一個主色、一個強調色；整份超過 4 種就要減少。 | Decktopus |
| 字型 | 最多 2 種，一種給標題、一種給內文；同一字型家族的不同粗細最理想。 | Decktopus |
| 字級 | 標題 40pt 以上；內文至少 24pt，現場投影時 30pt 以上更好。 | Decktopus |
| 對比 | 深色字配淺色背景，或淺色字配深色背景；避免淺灰字放在白底上。 | Decktopus |
| 字體樣式 | 用無襯線字體，避免全大寫、斜體和底線。 | PLOS |
| 元素數量 | 每頁 6 個元素以內；條列超過 5 點會顯得業餘。 | PLOS、Decktopus |
| 對齊 | 所有元素放在固定的網格上，每頁標題對齊同一條左邊線。 | Decktopus |
| 留白 | 內容周圍保留足夠空間，看起來有點空通常才是對的。 | Decktopus |
| 一致性 | 每頁相同的字型、顏色和版型，快速翻過要像同一個人做的。 | Decktopus |
| 圖像優先 | 能用圖片、圖表或圖解就不用大段文字；圖表拿掉格線、外框和雜亂的圖例。 | Decktopus、Mayer |
| 標註位置 | 說明文字直接放在它描述的圖旁邊。 | Mayer |
| 強調 | 用顏色、對比或醒目標示，把注意力引到重點。 | Mayer、Duarte |
| 可讀性檢查 | 站在約 3 公尺外看，看不清楚就加大字或提高對比。 | Decktopus |
| 配色友善 | 選擇色盲也能分辨的配色。 | PLOS |

> 字級建議是針對現場投影。只用於線上閱讀或在小螢幕上看的簡報，字級可以小一些。
